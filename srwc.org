**Investigation findings:**

The "Unable to start session" error occurs because srwc is a Wayland compositor but the system is configured with LightDM (an X11 display manager) and no wayland session file exists.

Root causes:
1. No wayland session `.desktop` file exists for srwc in `/share/wayland-sessions/`
2. srwc needs to be launched via its CLI (`srwc start`), not as a standard session
3. The current configuration has `services.xserver.enable = true` but doesn't create a wayland session entry

**Fix to add to readme.org (srwc window manager section):**

Add a wayland session file by creating a desktop entry in the nix config:

```nix
# Add to the srwc system config section (around line 670)
services.displayManager.sessionPackages = [
  (pkgs.writeTextDir "share/wayland-sessions/srwc.desktop" ''
    [Desktop Entry]
    Name=srwc
    Comment=Trackpad-first infinite canvas Wayland compositor
    Exec=srwc start
    Type=WaylandSession
    DesktopNames=srwc
 '')
];
```

This creates a `.desktop` file in the wayland-sessions directory so LightDM can present srwc as a selectable session option at login.
