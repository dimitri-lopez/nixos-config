#+title: Srwc

* Documentation & Features

Srwc is a spatial Wayland compositor built on the Smithay library. Unlike traditional tiling or floating window managers, it provides an infinite 2D canvas where windows can be placed and navigated freely.

**Key Concepts:**
- **Infinite Canvas:** Windows exist on a giant 2D plane. You pan your "camera" around to see different parts of it.
- **Continuous Zoom:** You can zoom in/out of the canvas smoothly.
- **Spatial Memory:** Windows stay where you put them on the canvas, even if you pan away.

**Trackpad & Mouse Controls:**
- **Pan Canvas:**
  - Trackpad: 3-finger swipe
  - Mouse: Click and drag on the background (Left Mouse Button)
- **Zoom:**
  - Trackpad: 2-finger pinch
  - Mouse: Scroll wheel (usually with a modifier like Super)
- **Window Management:**
  - Move Window: Alt + Left Click drag
  - Resize Window: Alt + Right Click drag
  - Center on Window: Super + Ctrl + Left Click

* Configuration Reference (~/.config/srwc/config.toml)

This section documents all available configuration options supported by the `srwc` compositor.

**Top-Level Options:**
- `mod_key`: String ("Super" or "Alt"). Default: "Super".
- `cycle_modifier`: String ("Alt" or "Ctrl"). Modifier held during window cycling.
- `focus_follows_mouse`: Boolean.
- `autostart`: Array of strings. Commands to run on startup.
- `env`: Table of key-value pairs for environment variables.
- `keybindings`: Table mapping strings (e.g., "Mod+Return") to actions (e.g., "exec foot").

**[input] Section:**
- **[input.keyboard]**
  - `repeat_rate`: Integer.
  - `repeat_delay`: Integer.
  - `layout`: String (e.g., "us").
  - `variant`: String.
  - `options`: String (XKB options).
  - `model`: String.
  - `layout_independent`: Boolean.
- **[input.trackpad]**
  - `tap_to_click`: Boolean.
  - `natural_scroll`: Boolean.
  - `tap_and_drag`: Boolean.
  - `accel_speed`: Float (-1.0 to 1.0).
  - `accel_profile`: String ("adaptive" or "flat").
  - `click_method`: String ("button-areas" or "clickfinger").
- **[input.mouse]**
  - `accel_speed`: Float.
  - `accel_profile`: String.
  - `natural_scroll`: Boolean.
- **[input.scroll]**
  - `speed`: Float.
  - `friction`: Float (momentum decay).

**[navigation] Section:**
- `animation_speed`: Float. Speed of camera transitions (lower is faster).
- `nudge_step`: Integer. Pixels to move window per nudge.
- `pan_step`: Float. Base panning speed for keyboard.
- `trackpad_speed`: Float.
- `mouse_speed`: Float.
- `friction`: Float. Momentum decay for flings.
- **[navigation.edge_pan]**
  - `zone`: Float. Distance from screen edge to trigger auto-panning.
  - `speed_min`: Float.
  - `speed_max`: Float.

**[zoom] Section:**
- `step`: Float. Factor per zoom increment (e.g., 1.1).
- `fit_padding`: Float. Padding used for "Zoom to Fit" actions.

**[background] Section:**
- `shader_path`: String. Path to a GLSL fragment shader for the background.
- `wallpaper_path`: String. Path to a static PNG/JPG image.

**[effects] Section:**
- `blur_radius`: Integer.
- `blur_strength`: Float.

**[decorations] Section:**
- `bg_color`: String (Hex or Color name).
- `fg_color`: String.
- `corner_radius`: Integer.

**[xwayland] Section:**
- `enabled`: Boolean. Default: true.

**[[window_rules]] (List of Tables):**
- `app_id`: String (regex match).
- `title`: String (regex match).
- `position`: [Integer, Integer].
- `size`: [Integer, Integer].
- `widget`: Boolean (pins window to background, excludes from focus cycle).
- `decoration`: String ("client", "server", or "none").
- `blur`: Boolean.
- `opacity`: Float (0.0 to 1.0).

**[[outputs]] (List of Tables):**
- `name`: String (e.g., "eDP-1").
- `scale`: Float.
- `transform`: String ("normal", "90", "180", "270", "flipped", etc.).
- `position`: "auto" or [Integer, Integer].
- `mode`: String (e.g., "1920x1080@60").
