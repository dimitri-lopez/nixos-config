** Boox tablet (Weylus - recommended)
Weylus works better with Boox over WiFi. Install on Boox from Play Store or F-Droid.

Usage:
1. Run ~weylus-start~ on laptop
2. On Boox: Open Firefox and go to URL shown (http://:1701)
3. Accept connection - tablet becomes drawing tablet

USB (no WiFi):
1. Run: ~adb reverse tcp:1701 tcp:1701 && adb reverse tcp:9001 tcp:9001~
2. On Boox: Open Firefox and go to http://127.0.0.1:1701

Note: droidux had USB issues with Boox.
#+begin_src nix :tangle ./modules/droidux.nix
{ pkgs, ... }:

{
  home.packages = with pkgs; [
    xournalpp
    weylus
    android-tools
  ];

  programs.bash = {
    enable = true;
shellAliases = {
      weylus-start = "weylus";
      weylus-usb = "adb reverse tcp:1701 tcp:1701 && adb reverse tcp:9001 tcp:9001 && weylus";
    };
  };
}
#+end_src
