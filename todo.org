** Kanata Features Detailed
*** Chords (defchordsv2)
Press multiple keys simultaneously → different action. V2 allows overlapping chords.

#+begin_src lisp
;; Basic syntax
(defchordsv2
  (j k) esc 50 all-released ()           ; j+k → esc (vim-style)
  (s d f) enter 50 first-release ()      ; s+d+f → enter
  (w e r) tab 50 all-released (nav sym)   ; chord disabled in nav/sym layers
)

;; Timing: 50ms = "instant", 100-200ms = must hold briefly
;; release-behavior: all-released, first-release, hold
#+end_src

Common endgame uses:
- vim escape: ~(j k)~ → ~esc~
- desktop switching: ~(w e)~ → left, ~(e r)~ → right
- brackets: ~(j l)~ → ~=~, ~(k l)~ → ~=~, ~(l ;)~ → -=~

*** Tap-dance
Same key tapped multiple times → different actions.

#+begin_src lisp
(defalias
  td-caps (tap-dance 200 (caps esc lctl))      ; 1tap=esc, 2tap=ctrl
  td-symbol (tap-dance 300 (; : ; :))     ; ; → ; ;; → : (shifted)
)

;; Eager variant: activates each tap immediately
td-eager (tap-dance-eager 500 (a b c d spc))
#+end_src

Endgame uses:
- Caps Lock → escape, hold → control
- Symbol key → quickly cycle through variations
- Layer toggle via tapping

*** Macros vs Dynamic Macros

| Feature  | Macros           | Dynamic Macros      |
|----------+------------------+---------------------|
| Timing   | Fixed delays     | Records real timing |
| Use case | Static texts     | Runtime recording   |
| Changes  | Must edit config | Record while typing |

#+begin_src lisp
;; Static macro - defined in config
(defalias
  email (macro d i m i t r l i @example.com)
  del-line (macro C-a C-k)
)

;; Dynamic macro - record at runtime
(defalias
  dmr (dynamic-macro-record 0)
  dmp (dynamic-macro-play 0)
  dms (dynamic-macro-record-stop)
)
;; Activate with a key, then type, then activate dms to save
#+end_src

*** Sequences (Leader keys)
Vim-like leader sequences. Press keys in sequence to trigger actions.

#+begin_src lisp
;; Basic: leader key triggers sequence mode
(defalias leader (ldr))

;; Define sequences
(defseq
  fk1 (lsft a)              ; leader+a = Shift+a
  fk2 (C-x C-c)            ; leader+x+c = exit emacs
  ge (unicode 🐧)           ; leader+g+e = penguin
)
(deflayer base
  _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _
  _ _ _ _ _ @leader _ _ _ _ _ _ _ _
)

;; In sequence mode, type: g e → outputs 🐧
;; Or use on-idle to auto-exit
(defseq
  ge (unicode 🐧) 50 on-idle
)
#+end_src

*** Virtual Keys (Fake keys)
Internal triggers not mapped to physical keys. Used for advanced logic.

#+begin_src lisp
(deffakekeys
  to-num (layer-switch numbers)
  enter-typing (layer-while-held typing)
)

;; Use in switch/conditional logic
(defalias
  fk (switch ((layer num)) @to-num break ()))
#+end_src

*** Mouse Actions
Move cursor, scroll, click - useful forno mouse setup.

#+begin_src lisp
(deflayer mouse
  _    @mwu @mwd @mwl @mwr _    _    _    _    _    @maup _
  _    mlft mmid mrgt _    _    _    _    _    _    _
  _    @mltp @mrtp @mmtp _    _    _    _    _    _    _
  _    _   @ms← @ms↓ @ms→ _    _    _    _    _    _    _)

;; mwu/mwd = wheel up/down
;; mlft/mmid/mrgt = left/middle/right
;; mltp/rtp/mmtp = left/right/middle press
;; ms←/↓/→ = mouse movement
#+end_src

*** One-shot Modifiers
Temporary modifier until next key press. Like Sticky Keys but better.

#+begin_src lisp
(defalias
  osh (one-shot 2000 lsft)    ; Shift for 2 seconds or next key
  osc (one-shot-press 1000 lctl) ; Hold releases on next press
  osr (one-shot-release 500 lmet)
)
#+end_src

Useful for: Ctrl+C Ctrl+V without holding, then auto-release

*** Templates
Reduce boilerplate by defining reusable patterns.

#+begin_src lisp
(deftemplate homerowmod (timeouttap timeouthold keytap keyhold)
  (tap-hold $timeouttap $timeouthold $keytap $keyhold))

;; Use: (t! homerowmod 200 200 a lmet)
;; Expands to: (tap-hold 200 200 a lmet)
(deftemplate homerowmodfiltered (timeouttap timeouthold keytap keyhold except-keys)
  (tap-hold-release-keys $timeouttap $timeouthold
    (multi $keytap (on-idle-fakekey to-base tap 20))
    $keyhold $except-keys))
#+end_src
